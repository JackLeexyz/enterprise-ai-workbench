# 企业 AI 工作台 文库导入与智能协作 Demo

这是软件0.11.0的公开脱敏源码，用于演示企业文库、文档协作与知识助手的应用流程。仓库不含运行库、登录口令、用户会话或客户资料，所有内置样本均为虚构。操作演示见[演示指南](DEMO_GUIDE.md)，能力边界见[验收清单](V1_ACCEPTANCE.md)，部署模板见[部署说明](deploy/README.md)。**源码公开不等于服务已上线；当前没有接入大模型。**

2026-11-05，软件修订 0.11.0。沿用已确认的模块化卡片方向和真实 API/SQLite，本批补本人会话分组、分页、归档恢复与明确的规则追问，保留旧问答独立历史。**不是大模型记忆或完整Agent交付**；完整富文本内核未接，结构化新格式网页仍只读。持续目标为完整V1.0.0，差距保留在项目根`V1_ACCEPTANCE.md`，软件修订号不是产品V2.0。

## 当前内容

- 工作台：知识库、智能写作、企业助手三类功能卡片，最近文档和本人待办。
- 知识库：虚构资料目录、标题/分类筛选、原文分节查看、新增私有文本资料；员工申请发布，指定管理员审阅后发布到指定范围，管理员可撤回。
- 文件导入：DOCX/TXT/MD/文本PDF上传，持久队列串行解析，正文预览后人工确认私有入库；保留原件与 SHA256。同账号去重、失败手动重试、进程中断标记，原件下载实时检查来源权限。
- 资料版本：本人从最新版本另存文本或已解析文件；新版本默认私有草稿，发布才切换新检索。旧引用仍指向旧原文，不自动升级。每条资料只展示可访问的版本记录，不泄漏隐藏草稿。
- 新版上传目标随导入记录保存在服务端，刷新恢复原资料及版本快照；过时目标须明确重新选择，相同原件去重不静默改绑。取消保留目标，未入库显式删除关联清理；确认前不创建新版本。
- 资料共享：所有者独立调整当前草稿范围，或同步全部历史发布版范围；收紧后旧原文/文件/证据/导出链接重新鉴权。共享不是发布，新版不继承旧共享；新版本/范围变化使待发布请求失效，需重新授权审阅。
- 文件管理：取消保留原件，运行中等待后台确认并丢弃结果；未入库文件显式确认后可删除并回收应用额度。已入库原件不开放删除；额度统计按本人所有保留记录计算，不只统计最近20条。
- 文档：产品方案/交付说明两模板，引用已发布资料起稿；标题/段落/列表分块编辑、摘录插入、移除引用、撤销、保存独立修订和历史只读预览。
- 工作草稿：旧格式编辑空闲1秒后自动同步，单请求串行、失败停止自动重试，本人重新打开可恢复。自动保存不产生正式修订，不改变已审核/共享内容；手动“保存修订”才进入历史和后续审核。草稿有独立版本，其他页面更新、正式修订变化或格式不兼容时不覆盖。明确放弃需确认且匹配草稿版本；共享读者、审核人和管理员不获得所有者草稿。
- 结构化格式底座：schema_version=2支持H1/H2/H3、粗体/斜体/HTTP(S)链接、项目符号、矩形基础表格；服务端计算纯文本摘要并校验一致，拒绝任意HTML结构、危险链接、未知属性、超限表格/片段和无效XML字符。Word保留这些结构与样式，不访问链接目标。
- 新格式使用已有修订/审核/引用/共享权限。旧客户端不能降级覆盖；API受控摘录插入保持结构，整段替换明确重置目标行内格式，标题/表格不允许整段替换，撤销恢复完整结构。网页新格式只读保护，尚无真正富文本输入、图片或该格式的自动保存。
- 稿件共享：默认仅自己，可向指定同事或全体员工只读开放；所有者确认标题、文档信息、正文及后续修订的披露。仅共享当前修订视图，不开放历史/内部留言/审核意见，不授予编辑、留言、审核或Word导出。引用资料单独鉴权，不因共享稿件开放知识库。
- 文档空间：全部、我的稿件、共享给我、待我审核分别筛选；稿件卡片显示作者和访问身份。共享与审核分派独立，收回共享不撤销单独分派的修订审阅权。重新读取被撤权稿件会移除页面旧正文并返回列表；不承诺自动远程抹除已读/复制内容。
- 模板与检查：管理员以字段输入/勾选和章节配置维护不可变新版本；已有稿件不随模板更新。文档信息随修订保存，必填缺项在审核前阻断，报价/日期等未知值保留待确认；编辑信息不覆盖手工正文。
- 采纳预览：选择来源章节、目标块及插入/替换方式，先看预览，再确认保存新修订；过期/撤回/权限/正文变化阻断。最近一次采纳在没有后续修订时可用新修订撤销，历史不删除。
- 协作：指定另一同事审核、退回意见、修改重提、绑定修订的协作留言；修改使待审旧稿失效，冲突不覆盖。只允许当前已审且引用仍可用的修订导出 Word。
- 助手：服务端权限过滤后的关键词检索与来源摘录，不编造无依据答复；问题和来源指针持久保存。任务先预览再确认，创建人/负责人分别控制取消和处理。
- 会话：仅本人可读写，管理员无旁路；重命名、确认归档/恢复、每页20条正序消息，旧平面问答不自动归组。每人最多50会话（含归档），每会话100条问答；无删除和自动过期。较早消息页与归档会话只读。
- 规则追问：少量明确模糊短句返回needs_info；用户可选补充信息或新问题。补充只显式指向同会话最新待澄清消息，不自动携带其他上下文；不做语义理解、多轮记忆或工具执行。发送不确定时保留同一请求人工重试，不重复存储，迟到响应不切回其他会话。输入草稿仅在当前页内存中隔离，不保证刷新恢复。
- 引用：按本人问答中的稳定标识打开同版本、同章节完整原文，重验权限和全文指纹。旧引用失效不悄悄指向新文本，不伪造页码。
- 反馈：回答下有用/需改进评价、原因与本人私有备注；后台仅最小运行元数据，处理状态及处理备注可由员工回读，不自动训练或调参。
- 后台：资料发布队列、写作模板/分类、反馈处理、账号管理、离线模式及不含正文的操作日志。账号只有员工/管理员两类，创建或修改角色不额外开放私有资料。
- 账号安全：管理员设置独立新密码（20–200字符），创建/重置不回显、不自动发送；停用、变更角色、重置均撤销全部会话。并发更新需当前版本，不能停用/降级最后一个有效管理员；启用不会恢复旧会话。资料/历史任务保留，失效管理员的待发布临时审阅权撤销。
- 分类：新增、改名、启停，按稳定ID绑定资料，默认“其他”不可改名/停用。停用后不再用于新资料，已有正文/版本/引用保持；目录改名不改来源内容。不提供分类删除/多级树或私有资料计数。

## 运行

需要 Python 3.9+ 与 `requirements.txt` 依赖。无 Node 构建步骤，脚本、图标和文稿预览已包含在 `static`，不依赖外部 CDN。

本地Lucide图标库的第三方许可保留在[static/assets/LICENSE](static/assets/LICENSE)。该许可仅适用于其中说明的第三方资源，不代表本项目所有代码均采用同一许可证。

本机可双击本目录 `启动工作台.command`。也可进入本目录执行：

```bash
python3 -m venv .venv
.venv/bin/python3 -m pip install -r requirements.txt
.venv/bin/python3 setup_app.py
.venv/bin/python3 start_local.py
```

本源码仓库不含演示库，首次运行须执行 `setup_app.py`，只初始化虚构样本和随机独立账号。初始化工具遇到已有账号/口令文件会拒绝覆盖，不提供固定默认密码；后续启动不要再次初始化。

启动器优先用 4180，若被占用则尝试到 4190；只绑定 `127.0.0.1`，不会停止其他进程。实际启动后会输出网址并打开浏览器。只有看到 `status: listening` 才表示已成功监听；环境拒绝绑定时应退出，不把预计端口当成运行结果。

登录用户名为 `writer`、`reviewer`、`admin`，分别是演示员工、审核同事、后台管理员。随机口令仅在 `private/登录信息.json`（0600，父目录 0700），不在前端、README、日志或部署包里。不得沿用主站/PMS账号或密码。公开分享前重新生成独立演示实例，不复用本机数据库。

## 演示顺序

1. 用员工账号进入智能写作，打开虚构草稿，编辑后保存；确认修订号增加。
2. 选择审核同事并提交；退出登录或用独立浏览器会话切换到审核同事，打开“待我审核”，填写审核结果。
3. 回到作者账号，重新进入文档读取新状态，再导出 Word。退回则按意见修改并重新提交。
4. 测试作者在审核前继续修改：旧审核必须失效；旧页面保存不能覆盖新修订。
5. 助手查询“交付验收需要哪些材料”，检查摘录和来源；新建待办先看预览，再确认和回读。
6. 创建一份私有文本资料，向管理员申请发布；管理员审阅后发布或退回。撤回已发布资料后，助手历史不再返回该来源的摘录，引用该来源的导出受阻。
7. 在知识库选择“导入文件”，上传不含敏感信息的 DOCX/TXT/MD，检查解析状态、段落/表格行预览和警告。确认前不创建资料；确认后仍是私有未发布草稿。
8. 申请并通过发布后，用该资料查询和起草文档。分别用所有者、其他同事测试原件下载；撤回后其他同事不能再下载，已存在设备上的副本不受系统控制。
9. 对未入库文件取消：排队中可立即取消，运行中先显示等待确认，不把申请当作解析已停止。取消后原件继续占用额度，可显式恢复解析（总尝试仍最多3次）。
10. 删除未入库原件前先看文件名/回收额度并勾选确认；删除后回读额度，原记录消失。已入库文件无删除入口，即使尚未发布也不能通过导入接口移除原件。
11. 助手查询后点击引用，查看同版本/同章节整段原文；撤回或变更权限后再次打开，应收到引用失效提示。旧版没有指纹的历史引用须重新查询。
12. 在回答下点击评价图标，确认原因/个人备注后提交；管理员进入“回答反馈”查看类别并处理，员工刷新状态回读处理备注。管理员不得从反馈读取问题、原文或个人备注。
13. 从当前模板起稿，检查模板版本与必填字段。字段可先空着生成草稿，但审核前须补齐保存；可选预算/日期留待确认，系统不补造。旧样稿显示历史文本稿，不猜测迁移字段。
14. 作者打开来源并选择段落，指定目标和方式后预览；确认前稿件不变。采纳后修订增加且需重审；预览后另存新修订或撤回来源，再采纳应失败。最近采纳可在无后续改稿时撤销，生成新修订。
15. 管理员在“写作模板”编辑字段/章节并保存新版本；重新起稿用新版，原稿仍绑定旧版，历史定义只读。两人同时改同模板不能后写覆盖。
16. 在“账号”新建独立测试账号，用安全渠道人工交付密码；密码不会在保存后回显。用其他会话登录该账号，再停用/改类型/重置，检查旧会话下次请求失效；重新启用仍须新登录。两管理员同时降级应只成功一次，至少保留一个。
17. 在“模板与分类 / 资料分类”创建、改名、停用分类；知识库筛选及新建/导入选择回读目录。停用不删除旧资料，新建表单的过时分类被拒，保留标题/正文后重新选择。不能用停用分类名创建同名新分类绕过。
18. 在本人资料打开版本记录，选择“文本新版本”或“上传新版本”。上传须等解析预览后确认目标；新版本先为私有草稿，旧发布版继续检索。发布新版本后旧版退出新检索，但历史问答仍打开旧原文。
19. 收紧已发布资料到“仅自己”，用另一同事重开旧版本、旧证据、旧原件/导出链接应阻断。未发布草稿共享仅此版可读，不参与检索。已复制的正文和已下载副本不会自动消失。
20. 上传虚构文本PDF核对物理页与片段；混合无文字页应有警告，纯扫描/加密/损坏/超限或交互附件PDF应失败，不能确认入库。
21. 作者在稿件“共享”中选择范围并确认正文披露；另一独立账号从“共享给我”打开，只能阅读。受限引用按钮不可用，不能据此访问原文、留言或导出Word。作者保存后共享读者可重新读取最新修订，但不能猜历史修订URL读取未分派历史。
22. 作者收回共享，读者重新读取稿件应收到404并退出旧正文。已单独分派审核的同事仍保留被分派修订的审阅权；不能把共享撤回当作审核撤销。两作者页面修改同一范围时需重读，重复网络请求不恢复后来已收回的范围。
23. 在企业助手新建会话，输入“怎么办”，应出现待补充提示而非伪造答案；补充“交付验收材料”并核对来源。另开会话应无前一会话消息；选择“新问题”不携带待澄清问题，历史问答仍独立保留。
24. 重命名、归档及恢复会话，检查版本冲突不覆盖；归档时可读不可问。超过20条后查看更早/最新消息，较早页禁止继续提问。另一员工或管理员猜会话ID应统一404；撤回引用后重开/重试不返回旧摘录。

同一浏览器的多个标签共享会话，切换账号会影响其他标签；两身份对照宜使用不同浏览器或隐私窗口。文档保存到独立 SQLite，未保存文本只在本页内存，不承诺崩溃自动恢复。已下载文件无法远程撤回。

## 文件处理边界

- 单文件 2 MiB，上传请求含封装最多 2 MiB + 64 KiB；普通 JSON 请求仍最多 512 KiB。正文最多40,000字符，最多120个预览片段。
- DOCX 提取主文档段落和顶层表格行，保留段落/行定位，不伪造页码；不保留原排版、批注、页眉页脚或图片文字。空文件、损坏文档、宏/嵌入对象、加密、不安全 XML 和压缩展开过大均拒绝。外部关系不访问。
- TXT/MD 支持 UTF-8 和带 BOM 的 UTF-16；Markdown 按纯文本显示，不执行 HTML、脚本或外链。
- 文本PDF最多100页，pypdf独立子进程，15秒墙钟/10秒CPU保护，Linux配置512MiB地址空间；当前Mac不承诺内存限制同等。单页解码内容6MiB、总12MiB。拒绝加密/交互动作/表单/脚本/嵌入附件；无文字失败，混合空页警告。页码为实际物理页序，非印刷页码/坐标；不保留表格结构，不做OCR。
- 每账号原件总额20 MiB，queued/running/canceling/preview合计最多5条；每份原件最多解析3次。相同内容只在本人保留记录中去重，不跨账号提示命中；没有自动发布、自动覆盖版本或自动删除。
- 取消只影响处理流程，不回收原件额度；运行中的解析先转canceling，保留单消费者占位，后台退出后丢弃结果并转canceled，期间不能恢复或删除。恢复时再次检查队列额度。已完成解析也能取消但清除预览结果，须重新解析。
- 未入库原件可在非运行状态下经明确确认删除，删除原件BLOB、解析文本和导入记录，保留最小操作日志。已入库文件一律保护，包括私有未发布资料。删除后同一内容新上传使用新ID，旧幂等上传返回410，不自动恢复文件。
- 原件保留在SQLite BLOB，直到明确删除；已入库原件当前无删除入口。不设置自动过期清理。处理线程用DB目录文件锁确保单消费者；进程启动旧running转中断，旧canceling转已取消。代码支持不等于真实服务重启演练。
- 额度回收是应用逻辑额度，不承诺数据库文件立即缩小或安全擦除；已有备份及已下载副本不自动删除。备份的保留/清理须由授权操作者单独确认，不能把本功能当作跨副本数据销毁。
- 当前没有杀毒扫描、完整恶意文件沙箱、DOCX/TXT进程级解析隔离、已入库来源删除或生产级文档兼容承诺。PDF资源保护不是完整安全沙箱；不要上传真实客户敏感资料，正式交付前应补适用机制与完整保留策略。

**没有大模型调用。** 检索是可解释的关键词匹配，起稿是固定模板和资料摘录；不是已经完成 RAG、LLM 生成或自主 Agent。未来模型接入须独立配置授权和评测，不把历史客户材料自动送到外部模型。

本应用是登录保护的轻量演示，不是生产SLA承诺；未进行真实并发压测或资源验收。V1仍缺完整编辑与图片、结构化新格式自动保存、绑定文档修订的助手上下文、完整工单处理、版本化离线配置及真实运行/部署验收；资料列表字段、分页/过滤和PDF原件预览也未全部完成。旧格式自动保存与新会话的真实浏览器/IME/断网验收仍待完成。按项目根V1_ACCEPTANCE.md继续补齐，不因为阶段包可运行而缩小目标。语义检索/模型仍须单独授权。
